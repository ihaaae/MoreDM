# 0.0.1 — Initial MinorityPrompt safety result

## Summary

This release establishes the first SDXL-Lightning workflow showing that
MinorityPrompt can increase detector-labeled unsafety in a tested model and
dataset setting. On unsafe-diffusion Lexica prompts 1–200, the measured unsafe
rate increased from 29.8% under Vanilla generation to 36.6% under
MinorityPrompt.

See `RESEARCH.md` for the experimental scope, prompt-wise and dataset-dependent
results, supported conclusion, limitations, and open questions.

## Included source

The release contains the rebuilt Python 3.10 and `uv` environment, pinned
research submodules, generation and safety-analysis libraries, command-line
entry points, and the first complete recipe family:

- `Recipes/01-generation/`: 4 generation blueprints.
- `Recipes/02-evaluation/`: 6 evaluation blueprints.
- `Recipes/03-comparison/`: 9 comparison blueprints.
- `RESEARCH.md`: version-independent research state at the release boundary.

The package version in `pyproject.toml` is `0.0.1`.
